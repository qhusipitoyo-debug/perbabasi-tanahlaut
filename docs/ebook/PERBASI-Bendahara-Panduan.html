Edisi Pertama · 2026Kolofon

Panduan Aplikasi Bendahara — PERBASI Tanah Laut disusun sebagai pedoman resmi bagi Pengurus Kabupaten Tanah Laut (Perserikatan Baseball Softball Seluruh Indonesia) dalam mengoperasikan aplikasi pengelolaan keuangan dan persuratan organisasi secara digital.

Aplikasi ini dibangun menggunakan teknologi web modern tanpa biaya lisensi, dengan sistem keamanan JSON Web Token (JWT) dan penyimpanan data lokal (SQLite) sehingga seluruh data keuangan organisasi tetap berada di bawah kendali pengurus.

Tentang tangkapan layar

Seluruh gambar pada buku ini diambil langsung dari aplikasi versi berjalan. Angka, nama, dan transaksi yang tampak hanyalah data contoh; tampilan dapat sedikit berbeda pada perangkat Anda.

Buku ini disusun agar seluruh pengurus — mulai dari bendahara, sekretaris, hingga ketua — dapat mengoperasikan Aplikasi Bendahara PERBASI Tanah Laut dengan percaya diri: dari cara masuk (login), mencatat transaksi, mengelola kas beberapa rekening sekaligus, menagih iuran anggota, menerbitkan nomor surat resmi secara otomatis, hingga mencetak laporan pertanggungjawaban.

Bab 1Pendahuluan & Gambaran Aplikasi

Aplikasi Bendahara PERBASI Tanah Laut adalah aplikasi resmi pengurus untuk mengelola seluruh urusan keuangan dan administrasi organisasi secara digital: dari kas dan transaksi, iuran anggota, hingga penerbitan nomor surat keluar dengan format resmi organisasi.

1.1 Manfaat Aplikasi

  • Pencatatan keuangan rapi — setiap rupiah (pemasukan/pengeluaran) tercatat dengan tanggal, kategori, kas, dan bukti (no. bukti).
  • Transparansi & akuntabilitas — saldo setiap kas terhitung otomatis dari mutasi; grafik 6 bulan memudahkan rapat evaluasi.
  • Penagihan iuran terukur — status lunas/belum per anggota per bulan, tinggal klik.
  • Laporan resmi siap dicetak — laporan arus kas bisa langsung dicetak (A4) atau diunduh CSV untuk arsip/rapat.
  • Administrasi surat otomatis — nomor surat keluar terbit otomatis dengan format resmi, misal 400.4.1/001/PERBASASI-TALA/2026.
  • Keamanan berlapis — login JWT, password ter-enkripsi (scrypt), pembatasan percobaan login, audit log.

1.2 Modul Utama Aplikasi

1.3 Data tersimpan di mana?

Seluruh data (transaksi, anggota, iuran, surat, pengguna) tersimpan dalam satu database SQLite di server aplikasi (data/perbasasi.db). Tidak ada data yang dikirim ke pihak ketiga. Karena itu backup berkala wajib dilakukan (lihat Bab 11) sehingga data aman dari kerusakan/pencurian perangkat.

Siapa boleh memakai?

Pengurus dengan akun resmi dari administrator organisasi. Ada dua peran: ADMIN (kelola pengguna, backup, hapus data) dan BENDAHARA (operasional keuangan sehari-hari). Lihat Lampiran B untuk detail hak akses.

Bab 2Cara Masuk (Login) & Keamanan Dasar

2.1 Halaman Masuk

Gambar 2.1 — Halaman masuk aplikasi (desktop)
Buka aplikasi melalui alamat yang dibagikan pengurus, misal http://localhost:8080 (di komputer sekretariat) atau URL daring yang diberikan administrator.
Ketik Username pada kolom USERNAME.
Ketik Password pada kolom PASSWORD — klik ikon mata untuk memperlihatkan/menyembunyikan ketikan.
Tekan tombol Masuk.

Keamanan wajib diketahui

  • Password standar (admin123 / bendahara123) HANYA untuk instalasi pertama dan wajib langsung diganti melalui menu Pengaturan → Keamanan.
  • Setelah 10 kali salah memasukkan password dalam 10 menit, akun Anda diblokir sementara oleh sistem.
  • Sesi login berakhir otomatis setelah 12 jam — cukup login kembali.
  • Jangan pernah membagikan password Anda — termasuk kepada sesama pengurus. Setiap orang punya akun sendiri.

2.2 Ganti Password

Klik menu Pengaturan di sidebar → tab Keamanan.
Isi: Password Lama, Password Baru (minimal 6 karakter), dan konfirmasinya.
Klik Ubah Password — selesai.

2.3 Keluar dari Aplikasi

Klik tombol Keluar di bagian bawah sidebar (atau ikon logout di pojok). Selalu keluar jika memakai komputer bersama.

Praktik baik

Gunakan password minimal 8 karakter kombinasi huruf & angka, contoh: Talat2026!basket. Jangan gunakan tanggal lahir yang mudah ditebak.

Bab 3Memasang di HP (PWA) & Akses Online

Aplikasi ini adalah Progressive Web App (PWA) — artinya bisa dipasang ke layar utama HP seperti aplikasi asli, tanpa perlu Play Store.

3.1 Memasang di Android (Chrome)

Gambar 3.1 — Tampilan dashboard di layar HP
Buka alamat aplikasi di Google Chrome pada HP Anda.
Ketuk menu ⋮ (tiga titik) di pojok kanan atas.
Pilih Tambahkan ke layar utama (atau Install app).
Ikon Perbasasi Bendahara muncul di layar HP — buka dari sana, tampil layar penuh seperti aplikasi native.

3.2 Akses dari mana saja (online)

Saat aplikasi ditayangkan secara daring (hosting), seluruh pengurus bisa mengakses dari mana pun tanpa terbatas jaringan kantor:

https://goes-habitat-tile-cylinder.trycloudflare.com

* URL daring dapat berubah sesuai konfigurasi server dan hanya dibagikan kepada pengurus internal. Jika URL tidak terbuka, hubungi administrator TI organisasi.

Aturan penggunaan daring

  • Bagikan alamat dan akun hanya kepada pengurus yang berwenang.
  • Hindari masuk dari Wi-Fi publik yang tidak terpercaya (kafe, terminal, dll).
  • Jangan menyimpan password di browser komputer bersama.

3.3 Akses dari komputer sekretariat (jaringan lokal)

Di komputer sekretariat aplikasi berjalan di http://localhost:8080. Komputer lain dalam satu Wi-Fi/LAN kantor dapat membuka lewat alamat IP komputer server, misalnya http://192.168.100.5:8080 — mintalah alamat persisnya kepada administrator.

Bab 5Mengelola Transaksi Keuangan

Gambar 5.1 — Menu Transaksi dengan filter dan ringkasan

5.1 Menambah transaksi

Klik Tambah Transaksi di kanan atas.
Pilih Tipe: Pemasukan atau Pengeluaran.
Isi Nominal (Rp, tanpa titik/koma — cukup angka), Tanggal, pilih Kas dan Kategori sesuai tipe.
Isi No. Bukti bila ada (opsional) dan Keterangan yang jelas — misal “Setoran iuran bulan Oktober — rekening BRI”.
Klik Simpan Transaksi. Saldo kas langsung diperbarui.

5.2 Mencari & memfilter

Gunakan kotak pencarian (keterangan / no bukti / kategori) dan filter tipe, kas, kategori, serta rentang tanggal. Ringkasan Total Pemasukan / Pengeluaran / Selisih mengikuti filter yang aktif.

5.3 Mengubah & menghapus

Klik ikon pensil (ubah) atau tempat sampah (hapus) pada baris transaksi. Hapus meminta konfirmasi dan tidak bisa dibatalkan — tercatat di audit log.

5.4 Export CSV

Klik tombol CSV untuk mengunduh transaksi sesuai periode filter (bisa dibuka di Microsoft Excel / LibreOffice Calc).

Catatan akuntansi sederhana

Setiap uang masuk di organisasi wajib dicatat sebagai pemasukan pada saat diterima, dan setiap uang keluar dicatat sebagai pengeluaran. Jangan menumpuk struk untuk diinput belakangan — input segera, sekecil apa pun nominalnya.

Bab 6Mengelola Kas & Kategori

Gambar 6.1 — Kelola kas, kategori pemasukan/pengeluaran, dan bidang surat

6.1 Kas (multi-rekening)

Organisasi dapat memiliki beberapa kas sekaligus, misalnya Kas Tunai Sekretariat, Bank BRI Perbasasi, atau E-Wallet. Setiap kas memiliki saldo awal dan saldonya terhitung otomatis dari seluruh transaksi yang tercatat (masuk − keluar).

Klik + Kas → isi nama kas, tipe (kas tunai / rekening bank / e-wallet / lainnya), saldo awal, catatan → Simpan.
Ubah dengan ikon pensil atau hapus dengan ikon tempat sampah (hanya kas yang belum dipakai transaksi dapat dihapus).

6.2 Kategori transaksi

Di kolom Pemasukan dan Pengeluaran Anda dapat menambah/mengubah/menghapus kategori (misal: “Iuran Anggota”, “Donasi & Sponsor”, “Konsumsi”). Kategori membantu dashboard menampilkan diagram pengeluaran per pos biaya. Kategori yang masih dipakai transaksi tidak bisa dihapus.

6.3 Bidang surat

Kolom Bidang Surat mengelola klasifikasi surat keluar untuk modul Persuratan (lihat Bab 10). Lima bidang bawaan: Bidang Olahraga (OR), Bidang Kepelatihan (KP), Bidang Wasit & Pertandingan (WP), Bidang Pembinaan & Usia Dini (PB), Administrasi & Kesekretariatan (ADM). Dapat ditambah/diubah/dihapus sesuai kebutuhan organisasi.

Bab 7Data Anggota

Menu Anggota dipakai sebagai database induk atlet, pelatih dan pengurus — sekaligus menjadi dasar penagihan iuran (Bab 8).

7.1 Menambah anggota

Klik Tambah Anggota.
Isi: No. Anggota (opsional, misal PB-007), Nama lengkap (wajib), Tanggal bergabung, Posisi/Jabatan (Guard, Pelatih, dll), Tim/Kelompok, Telepon.
Simpan — anggota langsung dapat dicatat iurannya.

7.2 Mencari & status keanggotaan

Gunakan kotak pencarian dan filter status (Aktif/Nonaktif). Anggota nonaktif tidak muncul di daftar penagihan iuran dan tidak dihitung dalam statistik anggota aktif. Gunakan status ini (bukan menghapus) ketika anggota keluar/nonaktif — riwayat iurannya tetap aman.

Struktur data yang disarankan

  • Posisi/Jabatan: posisi bermain (Guard/Center/Forward), peran pelatih (Pelatih Tim Putri), atau jabatan pengurus (Bendahara, Sekretaris).
  • Tim/Kelompok: Tim Putra Elite, Tim Putri, Tim Junior, atau Pengurus untuk non-atlet.

Bab 8Iuran Anggota

Gambar 8.1 — Menu Iuran Anggota per periode

8.1 Mencatat pembayaran iuran

Pilih Periode bulan di kanan atas (contoh: November 2026).
Untuk anggota yang sudah membayar, klik Catat Bayar.
Isi nominal (otomatis terisi sesuai Nominal Iuran Default di Pengaturan), tanggal bayar, dan catatan (misal “transfer BRI a.n. Bendahara”).
Simpan — anggota langsung berstatus LUNAS.

8.2 Membatalkan pembayaran

Jika terjadi kesalahan input, klik tombol Batalkan pada baris anggota tersebut — sistem meminta konfirmasi. Data iuran periode itu dihapus dan anggota kembali berstatus BELUM.

8.3 Ringkasan & export

Empat kotak ringkasan (total anggota, lunas, belum, terkumpul) dan progress bar muncul di atas tabel. Tombol Export CSV mengunduh daftar iuran periode berjalan untuk diarsip/rapat.

Tips penagihan

Lakukan pengecekan iuran tiap akhir minggu pertama bulan berjalan, lalu umumkan di grup resmi — jumlah Belum Bayar yang tampil di layar bisa langsung dijadikan daftar tagih.

Bab 9Laporan Arus Kas & Cetak Resmi

Gambar 9.1 — Laporan Arus Kas dengan ringkasan periode

9.1 Menampilkan laporan

Klik menu Laporan di sidebar.
Pilih rentang Dari–Sampai (default: awal bulan sampai hari ini) → klik Tampilkan.
Laporan berisi rincian transaksi per tanggal beserta total pemasukan, pengeluaran dan selisih periode.

9.2 Cetak resmi (A4)

Klik tombol Cetak — tampilan laporan berubah menjadi dokumen bersih berkop PERBASI TANAH LAUT lengkap dengan periode, total, selisih dan tanggal cetak, siap ditandatangani pada rapat pengurus. Gunakan ukuran kertas A4.

9.3 Unduh CSV

Klik tombol CSV untuk mengunduh rincian laporan sebagai file spreadsheet.

Lampiran wajib rapat

Untuk rapat evaluasi bulanan, cetak (1) Laporan Arus Kas periode berjalan, dan (2) export CSV iuran — keduanya cukup dari layar ini, tanpa rekap manual.

Bab 10Persuratan & Penomoran Otomatis

Menu Persuratan mengelola seluruh surat keluar organisasi. Nomor surat diterbitkan otomatis oleh sistem dengan format resmi organisasi:

400.4.1 / 001 / PERBASASI-TALA / 2026

400.4.1 = kode klasifikasi surat · 001 = nomor urut (reset tiap tahun) · PERBASASI-TALA = kode organisasi · 2026 = tahun

Gambar 10.1 — Generator nomor & arsip surat keluar

10.1 Membuat surat baru

Klik Buat Surat Baru (atau tombol Buat Surat Nomor Ini pada kartu generator).
Isi Tanggal Surat, Sifat (Biasa/Penting/Segera/Rahasia), Perihal, Ditujukan Kepada (Yth.), pilih Bidang, Lampiran, dan Isi Surat (yang akan tercetak).
Simpan — nomor terbit otomatis dan tampil sebagai notifikasi, contoh: “Surat terbit dengan nomor 400.4.1/001/PERBASASI-TALA/2026”.

10.2 Generator nomor (tanpa membuat surat)

Kartu gelap di atas halaman menampilkan nomor berikutnya untuk tahun yang dipilih. Tombol Salin Nomor menyalinnya ke clipboard — berguna bila nomor dipakai untuk dokumen lain di luar aplikasi.

10.3 Cetak kop surat resmi

Klik ikon printer pada baris surat — jendela baru menampilkan kop surat resmi PERBASI Tanah Laut (logo, nama organisasi, alamat, telepon), nomor–lampiran–perihal, tanggal, isi surat, dan blok tanda tangan pejabat penandatangan — lalu langsung membuka dialog cetak A4.

10.4 Arsip & export

Semua surat terarsip rapi: cari dengan kata kunci, filter per bidang/sifat/tahun, cetak ulang, ubah, atau hapus. Tombol CSV mengunduh arsip sesuai filter. Nomor yang sudah terbit tidak berubah; bila tahun pada tanggal diubah, nomor dapat dibuat ulang (centang “Buat ulang nomor” pada formulir ubah).

Urutan nomor dijamin server

Nomor diterbitkan saat menyimpan — aman meski dua pengurus membuat surat bersamaan; keduanya mendapat nomor berbeda (tidak pernah bentrok). Nomor berjalan urut per tahun dan kembali ke 001 setiap tahun baru.

Bab 11Pengaturan, Pengguna & Backup Database

Gambar 11.1 — Tab Pengaturan → Organisasi

11.1 Tab Organisasi

Mengelola identitas resmi organisasi: nama, tagline, alamat, telepon, email, nominal iuran default, serta Kode Klasifikasi & Kode Organisasi pada nomor surat (default 400.4.1 dan PERBASASI-TALA) dan nama pejabat penandatangan kop surat.

11.2 Tab Keamanan

Ganti password akun Anda (lihat Bab 2). Tampilan ini juga menunjukkan username & peran Anda saat ini.

11.3 Tab Pengguna — khusus admin

  • Tambah pengguna: isi username, password awal (min. 6 karakter), nama lengkap, peran (bendahara/admin).
  • Ubah pengguna: ganti nama, peran, atau menonaktifkan akun (nonaktif = tidak bisa login, data tetap ada).
  • Reset password: administrator dapat menyetel ulang password pengguna (misal jika lupa).
  • Sistem menolak penghapusan semua admin aktif — minimal satu admin selalu tersisa.

11.4 Tab Audit Log — khusus admin

Daftar 100 aktivitas terakhir: siapa, kapan, dan apa yang dilakukan (login, tambah/ubah/hapus data, ganti pengaturan, backup). Berguna untuk menelusuri “siapa yang menghapus transaksi itu?”.

11.5 Tab Backup — cara aman mem-backup database

Menu Pengaturan → Backup → klik Unduh Backup Sekarang.
File backup-perbasasi_….db terunduh — simpan di dua tempat berbeda (misal flashdisk + Google Drive/kirim ke email pribadi).
Lakukan minimal seminggu sekali dan selalu setelah rapat keuangan.

Mengapa backup penting?

Database adalah satu-satunya salinan seluruh data keuangan & arsip surat organisasi. Backup adalah asuransi termurah dan tercepat ketika perangkat rusak atau terserang virus.

11.6 Mengembalikan (restore) backup

Restore dilakukan administrator TI: matikan aplikasi → salin file backup menjadi data/perbasasi.db → jalankan kembali aplikasi. Seluruh data kembali seperti saat backup diunduh.

Bab 12Mode Gelap & Kustomisasi Tampilan

Gambar 12.1 — Tampilan mode gelap

Klik ikon matahari/bulan di bilah atas untuk berganti terang/gelap — cocok untuk operasional malam. Preferensi tersimpan di perangkat masing-masing (tidak mengubah tampilan pengurus lain).

Di ponsel, seluruh menu mengecil menjadi ikon — ketuk ikon garis (burger) di kiri atas untuk membuka/tutup sidebar.

Bab 13Tanya Jawab (FAQ) & Solusi Masalah

Aplikasi tidak bisa dibuka

“This site can’t be reached” → aplikasi di komputer server belum berjalan. Mintalah administrator menjalankan npm start di komputer sekretariat.

Dari HP tapi gagal → pastikan alamat yang dipakai benar; jika memakai URL daring, tanyakan ke admin apakah server sedang aktif.

“Endpoint tidak ditemukan” saat membuka menu

Biasanya aplikasi di server adalah versi lama. Minta administrator menghentikan lalu menjalankan ulang aplikasi (Ctrl+C kemudian npm start), lalu refresh layar dengan Ctrl+Shift+R.

“Username atau password salah” / “Terlalu banyak percobaan login”

Periksa Caps Lock dan penggunaan spasi. Jika terblokir, tunggu 10 menit atau minta admin mereset password Anda (Pengaturan → Pengguna → Reset Password).

Nomor surat muncul ganda / lompat

Nomor diterbitkan server secara berurutan; nomor yang dihapus tidak dipakai ulang — ini normal dan justru baik untuk arsip (jejak audit). Bila harus mengganti, admin dapat menghapus surat salah dan membuat ulang; nomor berikutnya tetap berjalan dari yang tertinggi.

Saldo kas tampak salah

Saldo = saldo awal + mutasi transaksi. Periksa transaksi dengan filter Semua kas, perhatikan kategori dan kas yang tercatat. Jika saldonya tetap aneh, bandingkan dengan buku kas fisik — perbedaan paling sering berasal dari transaksi yang belum diinput.

Cetak surat/laporan tidak muncul preview

Izinkan popup di browser untuk alamat aplikasi. Alternatif: unduh CSV lalu cetak dari Excel.

Layar muncul kosong/“Memuat…” terus

Refresh dengan Ctrl+Shift+R. Jika masih sama, keluar lalu login kembali. Bila berulang, hubungi administrator — kemungkinan aplikasi perlu dijalankan ulang.

Kontak bantuan

Laporkan kendala teknis ke administrator TI organisasi beserta: (1) jam kejadian, (2) menu yang dibuka, (3) pesan error yang muncul persis, (4) screenshot bila memungkinkan.
